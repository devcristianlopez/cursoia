06 / Preparar · Atajo de Codespaces

Un atajo menos.
Un conflicto menos.

  1. En Codespaces abre la paleta con Ctrl+Shift+P.
  2. Busca Keyboard Shortcuts.
  3. Busca Go to File o Quick Open.
  4. Quita o cambia el atajo Ctrl+P.
  5. Prueba que Ctrl+P ya no abra archivos en VS Code.
POR QUÉ

OpenCode también usa Ctrl+P

Si Codespaces captura el atajo, el menú de OpenCode no aparece o se vuelve confuso.

El objetivo es que el terminal reciba la combinación cuando estés usando OpenCode.

Plan B: si el navegador o el layout del teclado no lo permiten, usa el comando equivalente dentro de OpenCode y avisa antes de avanzar.
Guía docente · 5 min

19 / Especificar · contrato observable

Antes del código,
cinco comprobaciones.

  1. “Estudiar listas” aparece como pendiente al agregarla.
  2. Texto vacío o espacios muestra aviso y no crea una tarea.
  3. Completar una tarea cambia solo esa tarea.
  4. Cada filtro muestra el subconjunto correcto.
  5. Los reruns de la sesión mantienen la lista; una sesión nueva empieza vacía.
TU DECISIÓN

Revisa → ajusta → confirma

“Apruebo este alcance. Implementa por pasos pequeños y muéstrame cómo verificar cada uno.”

Guía docente · 4 min

Acordar qué ocurre con títulos duplicados: pueden permitirse, pero completar una tarea no debe completar otra por error. Pedir identificadores estables si hace falta. Probar sesión nueva en una ventana privada; no confundir rerun con reconexión.

28 / Cerrar sin perder el trabajo

Código guardado.
Memoria respaldada. Cómputo detenido.

git status --short
git diff
# Ejemplo: agrega solo archivos existentes y revisados.
git add app.py pyproject.toml uv.lock
git diff --cached
git commit -m "feat: primera app verificable"

Agrega también lógica y tests usando sus rutas reales. No uses git add . sin revisar. No hay push automático.

  • Un commit es local. Guarda también el repo en un remoto propio o descarga un respaldo.
  • Un commit no guarda PostgreSQL. Respalda la memoria por separado.
  • Detén el Codespace desde GitHub al terminar.

Detener el cómputo no elimina el almacenamiento: puede seguir consumiendo cuota o generar costo.

Guía docente · 7 min

Verificar archivos antes de copiar git add; el agente puede haber elegido otras rutas. Si Git pide identidad, configurar según las políticas del alumno, sin modificar globalmente sin consentimiento. Los labs son repos independientes: no tienen remoto por defecto. Ayudar a asociar un remoto propio y hacer push solo por decisión explícita, o descargar respaldo. Antes de borrar un Codespace, respaldar repos y PostgreSQL con el procedimiento ensayado; vault opcional no garantiza recuperación completa. Confirmar que el Codespace diga detenido.
