# Taller de programación con IA

- Este repositorio contiene una presentación HTML autocontenida y material de taller en español; no usa Astro, npm ni compilación.
- Mantener `index.html` utilizable sin conexión, sin fuentes, scripts ni estilos externos. Los enlaces de documentación sí requieren conexión.
- Preservar navegación por teclado, contraste, foco visible y diseño adaptable. Evitar dependencias nuevas para esta primera versión.
- Ver presentación: `python -m http.server 8080`, abrir http://localhost:8080.
- El entorno Codespaces se prepara manualmente como ejercicio; nunca instalar agentes en `postCreateCommand`.
- No ejecutar instaladores, sudo, publicar, hacer commit ni subir cambios sin autorización específica.
- No incluir secretos, bases de datos, memoria privada de Lemoria ni soluciones completas de los ejercicios.
- Validar Bash y JSON; documentar qué se comprobó y qué sigue pendiente de ensayo real.
